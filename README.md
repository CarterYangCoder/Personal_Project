# 我的暑假生活

原生微信小程序前端项目，用故事化页面记录杨思睿的 2026 暑假，并把个人展示延伸为可持续使用的公益、学习与生活记录工具。

## 运行方式

1. 打开微信开发者工具，选择“导入项目”。
2. 选择本项目根目录 `D:\MobileDevelopment\Individual_Project1`。
3. 使用现有 AppID（或改为自己的测试 AppID）后，点击编译即可预览。

## 页面

- `pages/index`：渐变夏日启动页，约 1.2 秒后自动进入首页，也支持轻触进入；同一会话内再次进入会直接跳过。
- `pages/home`：以“首页 / 个人”双模块组织。未登录时首页只展示四个功能入口；登录后可在个人模块管理资料、查看自己的填写概览与退出登录。
- `pages/assistant`：夏日 AI 助手；结合当前账号保存在本机的待办、计划、公益意向和日记，提供今日安排、计划拆解、公益推荐与日记灵感，并可跳转到对应功能页。
- `pages/login`：通过云函数获取当前微信用户标识，头像上传到云存储，昵称与资料按账号保存。
- `pages/work`：每日工作日志；支持自定义日期、起止时间、任务类型、过程、成果与状态，按天形成时间轴，同时保留《新生手册》项目回顾。
- `pages/volunteer`：“志愿服务一起做”模块，持续发布线上筹资、闲置物品众筹与敬老陪伴项目；支持查看项目需求、提交和管理参与意向。
- `pages/study`：每日学习手账；可记录日期、时间、学科、优先级、学习目标、复盘和状态，按天形成时间轴，并保留四象限概览与自定义番茄钟。
- `pages/daily`：每日生活手账；可记录日期、时间、分类、心情、重要标记和生活内容，按天形成时间轴，同时保留每日一歌与收藏。

## 结构

`data/summer.js` 统一维护时间轴、快捷入口与公益项目数据；`components/` 提供时间轴、进度条和快捷入口卡片。未登录用户可以浏览功能说明；工作待办、公益意向、学习计划、番茄钟设置、歌曲收藏和生活日记只会在登录后展示。

账号数据采用“本地缓存 + 云端同步”的方式：修改会立即写入本机，并通过 `utils/record-store.js` 加入幂等同步队列；网络恢复后自动重试。云函数从可信上下文读取 OPENID，所有记录由服务端写入 `_openid`，更新和删除同时校验记录归属。旧版本本地记录会在首次同步时迁移到云端。

AI 助手通过 `dataService` 云函数调用 DeepSeek，配置方式见 `cloud-database.md`。密钥只保存在云函数环境变量中；云服务不可用时会自动回退到本地建议。

## 本地检查

```bash
npm run check
npm test
```

检查脚本不依赖第三方包，会验证项目内 JavaScript 语法和 JSON 格式；测试覆盖离线缓存与同步队列的核心行为。
